Quick start

Get Beacon running in under 2 minutes.

01

Create an account

Visit beacon.dev and sign up with GitHub or email.

02

Generate your API key

In settings, create a new key. You'll paste it into your IDE next.

03

Install the extension

Search "Beacon" in your IDE's marketplace and install.

04

Authenticate

Paste your key when prompted. Beacon starts reviewing immediately.

Privacy first. All review happens locally. Your API key only validates your account — code never leaves your machine.

IDE integration

Beacon shows issues inline as you type — no separate dashboard to check.

Inline diagnostics

Security issues appear as red squiggles, just like lint errors. Hover for detail and a suggested fix.

Code actions

Press Ctrl+. (Cmd+. on Mac) to see fixes. Apply with one click.

Status bar

The Beacon icon shows your current risk score. Click for the full file report.

MCP protocol

Connect Beacon to Claude Code, Cursor, or any MCP-compatible agent for automated review.

Start the server

beacon-server --port 3001 --api-key $BEACON_KEY

Send code for review

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "beacon/review",
  "params": {
    "code": "const key = process.env.API_KEY",
    "language": "typescript",
    "filename": "auth.ts"
  }
}

API reference

A REST API for integrating Beacon into your own tools.

POST /v1/review

Review code and return security issues.

curl -X POST https://api.beacon.dev/v1/review \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"code":"...", "language":"typescript", "filename":"app.ts"}'
POST /v1/batch

Review multiple files in one call.

curl -X POST https://api.beacon.dev/v1/batch \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"files":[{"code":"...","language":"typescript","filename":"a.ts"}]}'

Configuration

Create a beacon.config.json at your project root.

{
  "severity": {
    "hardcoded_secret": "error",
    "weak_crypto": "warning",
    "unsafe_deserialization": "error"
  },
  "ignore": ["node_modules", "dist", "build"],
  "languages": ["typescript", "python", "java", "go"],
  "local_only": true
}

Security rules

Checks Beacon runs across all supported languages.

Hardcoded secrets

API keys, tokens, passwords in source

SQL injection

Dynamic queries without parameterization

Weak crypto

Deprecated or insecure algorithms

Path traversal

Unsafe file system access patterns

Frequently asked

Does my code leave my machine?

No. All analysis runs locally. Your API key only validates your account.

What languages does Beacon support?

Python, TypeScript, JavaScript, Java, Go, Rust, and C/C++.

How fast is it?

Under 40ms on average — fast enough to run as you type.

Can I use Beacon offline?

Yes, fully — the IDE extension doesn't need internet to review code.

Can I customize the rules?

Yes, with beacon.config.json — set severity or disable specific checks.
